# Autonomous Web Scraper Pipeline

A lightweight, automated web scraper built with Python and scheduled via GitHub Actions to run daily without needing a local server.

## Tech Stack
* Python 3.10
* Requests & BeautifulSoup4
* GitHub Actions (CI/CD)

## How to Use
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python scraper.py`
